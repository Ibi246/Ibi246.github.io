Project 5: Text Processing and Word Frequency Analysis with NLP

← Back to Portfolio

Overview

This project applies Natural Language Processing (NLP) techniques to analyze literary texts, specifically "Alice's Adventures in Wonderland" by Lewis Carroll. Students learn to process raw text data, remove noise through filtering and lemmatization, and extract meaningful insights about word frequency patterns that reveal thematic content.

Project Objectives

  • Load and manage large text datasets efficiently using caching
  • Implement text preprocessing techniques to improve analysis quality
  • Use SpaCy library for advanced tokenization, lemmatization, and stop word removal
  • Calculate and visualize word frequency distributions
  • Compare results before and after preprocessing
  • Analyze how preprocessing affects interpretability of text data
  • Apply techniques to texts of personal choice and provide written analysis

Data Source

  • Text: Alice's Adventures in Wonderland by Lewis Carroll
  • Word Count: Approximately 27,500 words
  • Reason for Selection: Accessible from Project Gutenberg, well-known story enabling meaningful analysis, and class-friendly content

Core Technical Components

SpaCy NLP Library Integration

  • Loads the English language model (en_core_web_sm)
  • Provides tokenization, lemmatization, and linguistic analysis
  • Automatically identifies and removes stop words
  • Handles language-specific text normalization

Text Fetching and Caching System

  • fetch_text() function retrieves text from URLs with automatic caching
  • Uses SHA-1 hashing to create unique filenames for each URL
  • Implements error handling with user-friendly feedback messages
  • Avoids redundant network requests through local file storage
  • Creates organized directory structure for cached content

Text Processing Function

word_tokenization_normalization() function performs comprehensive preprocessing:

  • Converts text to lowercase for consistency
  • Tokenizes text into individual words and punctuation
  • Removes stop words (common words like "the", "and", "is")
  • Filters out punctuation marks
  • Eliminates numeric values
  • Removes very short words (less than 3 characters)
  • Applies lemmatization to reduce words to their base forms

Analysis Methodology

The project involves two stages:

  1. Initial Analysis - Counts word frequencies without preprocessing to show dominance of common words
  2. Refined Analysis - Applies full preprocessing pipeline to reveal meaningful thematic words and patterns

Expected Deliverables

  • Identification of the 15 most frequently used meaningful words
  • Comparison of preprocessed vs. non-preprocessed results
  • Written analysis (1-2 paragraphs) explaining what the words reveal about text themes
  • Explanation of why preprocessing is essential for effective text analysis
  • Application of techniques to a self-chosen text with complete analysis

Significance

This project demonstrates how data preprocessing transforms raw information into actionable insights, a critical skill in data science and natural language processing applications.
