Project 3: Enhanced Snowy Scene with Multiple Elements

← Back to Portfolio

Overview

This project builds upon Project 2 by introducing multiple compositional elements and improved spatial organization. The additions include more detailed scenery elements (sun, multiple houses, trees, and an enhanced snowman), demonstrating iterative design and refinement of graphics code.

Project Objectives

  • Extend basic drawing functions with specialized scene components
  • Implement multiple instances of objects (several houses and trees)
  • Improve spatial layout and centering of scene elements
  • Add detailed features to character elements (enhanced snowman)
  • Create reusable color schemes using data structures
  • Integrate multiple drawing functions into a cohesive scene

New Features Introduced

Expanded Color Palette

A colors list (["red", "blue", "brown", "yellow", "purple", "green", "lightblue", "black", "cyan"]) enabling varied visual elements and reusability

Specialized Drawing Functions

  • draw_sun() - Creates a yellow sun positioned at specific coordinates (-200, 150)
  • draw_house() - Combines a triangle roof with a square body, using the color array for variation
  • draw_tree() - Draws trees using circles with white fill color

Improvements from Project 2

  • Better Layout - Houses and trees are now centered and positioned more strategically
  • Enhanced Details - The snowman receives additional detail work for a more realistic appearance
  • Modular Design - Individual drawing functions for major scene elements make the code more organized and reusable
  • Visual Variety - The color array system allows for easy customization and variety in the scene

Technical Highlights

The project demonstrates composition patterns where complex scenes are built by calling multiple specialized functions, each handling a specific visual element while maintaining clean, readable code.
